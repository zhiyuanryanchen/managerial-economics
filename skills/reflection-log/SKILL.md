# /reflection-log · 反思日志

## 定位

全书与全程的「思辨黑匣子」。它记录的不是你得出什么结论，而是——**你为什么信、为什么不信**。

每一轮对练（`/case-challenge`、`/decision-gym`、各对练角色）都会在这里留下一条终审记录；结语阶段，它被用来做一次学期首尾呼应的元认知复盘。

## 思辨铁律

**人先产出 → AI 挑战 → 人终审裁决。**

日志记录的正是最后那一步——**人的裁决**。因此：

- AI **只引导提问，绝不代填**。
- 学生若跳过「接受／拒绝的理由」，记录视为无效。

## 记录结构（固定模板）

```
### 记录 <日期> · <场景／章节> · <使用的角色或技能>
- 我的初始判断：
- AI（角色）的挑战：
- 我接受的理由：
- 我拒绝的理由：
- 我改变了什么看法：
- 我还存疑的是：
```

## 工作流

1. **触发**：对练结束／学生主动／一个单元结束。
2. **引导填写**：AI 用提问帮助回忆（「你最后保留了哪条挑战？」「哪条你到现在也不服？」），**不替学生写内容**。
3. **画像统计**：定期生成「接受／拒绝 AI 理由」的频次与类型画像——你更常被什么说服？又常拒绝什么？
4. **结语复盘**：调出**学期第一条**记录，与当下对照，回答那个核心问题——「**我当初哪里错了？**」

## 输出模板（画像）

```
## 我的思辨画像（第 N 周）
- 我更常接受的挑战类型：……
- 我更常拒绝的挑战类型：……
- 我最反复出现的思维盲点：……
- 本周最值得记住的一条记录：……
```

## 结语 · 元认知复盘

```
## 我当初哪里错了
- 学期最初我的判断（摘自第一条记录）：
- 今天的我会怎么说：
- 改变发生在哪一次对练之后：
- 我现在的判断，最怕被谁挑战：
```

## 导出与使用边界

- **格式**：Markdown（可汇总为表格）。
- **去向**：学生个人留存；如用于**教学研究语料**，须经学生**明确授权**并匿名化处理。
- **隐私**：默认仅学生本人可见；教师仅在授权范围内查看汇总。

## 边界（禁止事项）

- ✗ 不得替学生代填任何字段。
- ✗ 不得在未授权时导出或展示学生个人记录。
- ✗ 不得把日志变成打分表——它服务于**复盘**，不是评价工具。

- 上游：`/case-challenge`、`/decision-gym`、五个对练角色。
- 下游：结语「我当初哪里错了」；授权后汇入教学研究语料。
