# /decision-gym · 决策健身房

## 定位

判断力像肌肉，只能靠**反复负重训练**长出。本技能把真实决策压缩成可重复的彩排：限时、信息不完全、即时见真章。

对应章节：**第 4 章（需求的定量分析）、第 8 章（市场结构下的策略）、第 9 章（博弈与战略互动）、第 10 章（改变规则）**。

## 思辨铁律

**人先产出 → AI 挑战 → 人终审裁决。**

在健身房版本里：**你先在限时内拍板 → 揭晓真实结果 → 你自己复盘偏差**。AI 不替你拍板，也不在揭晓时点评。

## 彩排三要素

| 要素 | 说明 |
|---|---|
| **限时** | 给一个短时限（如 3 分钟），逼出直觉与优先级。 |
| **角色信息卡** | 你是谁、你知道什么、你**不知道**什么——信息故意不完整。 |
| **即时揭晓** | 学生决断后立刻公布真实数据／结果，不加评论。 |

## 工作流

1. **选题**：从案例库选一个对应章节的决策点（如「提价一块钱，会丢掉多少顾客」）。
2. **发牌**：给出角色信息卡 + 时限 + 所需决策。
3. **限时决断**：学生写下——判断、理由、**最担心什么**。
4. **即时揭晓**：公布真实数据／后续结果，**先只给事实**。
5. **复盘归因**：请学生自答——
   - 是**信息不足**（牌没给全）？
   - 是**框架错**（用错了模型）？
   - 还是**运气**（结果对但推理错，或反之）？
6. **记录**：生成待填反思记录 → 交 `/reflection-log`。

## 角色信息卡模板

```
【角色】你是 ________（岗位）
【你知道】________
【你不知道】________（关键信息缺口）
【时限】________
【要决断】________
```

## 即时揭晓纪律

- 揭晓时**只给事实**，不给评价、不喊「你错了」。
- 学生先自我对照，再讨论；**教师的点评放在学生复盘之后**。
- 允许「结论对、推理错」与「结论错、推理对」同时出现——这正是训练价值所在。

## 输出模板

```
## 本次彩排
- 章节／场景：
- 角色：
- 限时：

## 我的决断
- 判断：
- 理由：
- 我最担心：

## 即时揭晓（事实）
>

## 偏差归因（请我填写）
- 信息不足／框架错／运气：
- 下次我会先问的问题：
```

## 边界（禁止事项）

- ✗ 不得在决断前透露结果或暗示方向。
- ✗ 不得做「事后诸葛亮」式点评——先让事实说话，再让学生自评。
- ✗ 不得因为学生「猜对了」就跳过复盘。

## 衔接

- 与 `/reflection-log`：每条彩排生成一条归因记录。
- 与 `/case-challenge`：彩排后如需深挖，进入结构化对辩。
